# Java Day 08 — Interview Questions

## 1. What is a loop in Java?

A loop is used to execute a block of code repeatedly while a specified condition is true.

---

## 2. What are the three main loops in Java?

* for loop
* while loop
* do-while loop

---

## 3. What is the difference between for and while loop?

for loop is commonly used when the number of iterations is known.

while loop is commonly used when the number of iterations depends mainly on a condition.

---

## 4. What is the difference between while and do-while loop?

while checks the condition before executing the loop body.

do-while executes the loop body first and checks the condition afterward.

---

## 5. What happens if a while loop condition is initially false?

The loop body executes zero times.

---

## 6. What happens if a do-while loop condition is initially false?

The loop body executes at least once.

---

## 7. What is an infinite loop?

An infinite loop is a loop that never terminates because its condition never becomes false.

Example:

```java
int i = 1;

while (i <= 5) {
    System.out.println(i);
}
```

Here, i is never updated, so the condition remains true.

---

## 8. What is the purpose of break?

break immediately terminates the loop.

Example:

```java
if (i == 5) {
    break;
}
```

---

## 9. What is the purpose of continue?

continue skips the current iteration and moves to the next iteration.

---

## 10. What is a nested loop?

A nested loop is a loop placed inside another loop.

Example:

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.println(i + " " + j);
    }
}
```

---

## 11. Can a for loop execute zero times?

Yes. If the condition is false before the first iteration, the loop body does not execute.

---

## 12. Can a for loop have multiple variables?

Yes.

Example:

```java
for (int i = 1, j = 5; i <= 5; i++, j--) {
    System.out.println(i + " " + j);
}
```

---

## 13. What is the difference between break and continue?

break → completely stops the loop.

continue → skips the current iteration and continues with the next iteration.

---

## 14. Can loops be nested inside each other?

Yes. A for, while, or do-while loop can be placed inside another loop.

---

## 15. What are common uses of loops?

Loops are commonly used for:

* Repeating calculations
* Processing arrays
* Generating patterns
* Searching data
* Reading multiple inputs
* Traversing collections
