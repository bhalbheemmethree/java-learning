# JAVA DAY 01

# JDK, JRE & JVM

# ==========================================================

# ==========================================================

# WHAT IS JAVA?

# ==========================================================

# Java is a high-level, object-oriented programming language.

# Java is used to build different types of applications.

# Java programs are compiled into bytecode.

# Bytecode is executed by the Java Virtual Machine (JVM).

# ==========================================================

# JAVA PROGRAMMING FLOW

# ==========================================================

# Java Source Code

#       ↓

# Java Compiler

#       ↓

# Bytecode

#       ↓

# JVM

#       ↓

# Program Output

# ==========================================================

# WHAT IS JDK?

# ==========================================================

# JDK stands for Java Development Kit.

# JDK is used to DEVELOP Java applications.

# It contains the tools required to write, compile,

# debug and run Java programs.

# JDK contains:

# JRE

# JVM

# Java Compiler

# Other development tools

# ==========================================================

# WHAT IS JAVAC?

# ==========================================================

# javac is the Java compiler.

# It converts Java source code into bytecode.

# Example:

# Main.java

#       ↓

# javac Main.java

#       ↓

# Main.class

# ==========================================================

# WHAT IS JRE?

# ==========================================================

# JRE stands for Java Runtime Environment.

# JRE provides the environment required to RUN Java applications.

# JRE contains:

# JVM

# Java runtime libraries

# Other runtime components

# ==========================================================

# WHAT IS JVM?

# ==========================================================

# JVM stands for Java Virtual Machine.

# JVM executes Java bytecode.

# JVM is responsible for running Java programs.

# JVM also performs important runtime tasks such as:

# Memory management

# Garbage collection

# Bytecode execution

# ==========================================================

# JDK VS JRE VS JVM

# ==========================================================

# JDK

# Java Development Kit

# Used to DEVELOP Java applications.

# Contains development tools.

#

# JRE

# Java Runtime Environment

# Used to RUN Java applications.

# Provides the runtime environment.

#

# JVM

# Java Virtual Machine

# Executes Java bytecode.

# ==========================================================

# SIMPLE RELATIONSHIP

# ==========================================================

# JDK

#  └── JRE

#       └── JVM

# ==========================================================

# JDK DEVELOPMENT TOOLS

# ==========================================================

# Some important JDK tools are:

# javac  → Java compiler

# java   → Runs Java applications

# javadoc → Generates Java documentation

# jar    → Creates Java archive files

# jshell → Interactive Java shell

# ==========================================================

# JAVA SOURCE CODE

# ==========================================================

# Java source code is the code written by the programmer.

# Java source files use the .java extension.

# Example:

# Main.java

# ==========================================================

# SIMPLE JAVA PROGRAM

# ==========================================================

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello Java");

    }

}

# Output

# Hello Java

# ==========================================================

# COMPILING JAVA CODE

# ==========================================================

# Java source code is compiled using javac.

# Command:

# javac Main.java

# After compilation, a .class file is generated.

# Example:

# Main.java

#       ↓

# javac Main.java

#       ↓

# Main.class

# ==========================================================

# BYTECODE

# ==========================================================

# Bytecode is the intermediate code generated by

# the Java compiler.

# Bytecode is stored inside a .class file.

# Example:

# Main.java

#       ↓

# Java Compiler

#       ↓

# Main.class

# ==========================================================

# RUNNING JAVA CODE

# ==========================================================

# Java bytecode is executed using the java command.

# Example:

# java Main

# Output

# Hello Java

# ==========================================================

# JAVA SOURCE CODE VS BYTECODE

# ==========================================================

# Source Code:

# Written by the programmer.

# File extension:

# .java

#

# Bytecode:

# Generated by the Java compiler.

# File extension:

# .class

# ==========================================================

# COMPLETE JAVA EXECUTION PROCESS

# ==========================================================

# Step 1:

# Programmer writes Java source code.

#

# Step 2:

# Source code is stored in a .java file.

#

# Step 3:

# javac compiles the source code.

#

# Step 4:

# Bytecode is generated.

#

# Step 5:

# Bytecode is stored in a .class file.

#

# Step 6:

# JVM loads and executes the bytecode.

#

# Step 7:

# Program produces output.

# ==========================================================

# COMPLETE FLOW

# ==========================================================

# Main.java

#      ↓

# javac Main.java

#      ↓

# Main.class

#      ↓

# JVM

#      ↓

# Program Output

# ==========================================================

# WHY DOES JAVA USE BYTECODE?

# ==========================================================

# Java uses bytecode so that the same compiled program

# can run on different platforms using a compatible JVM.

# Example:

# The same Java bytecode can run on:

# Windows

# macOS

# Linux

# ==========================================================

# JAVA IS PLATFORM INDEPENDENT

# ==========================================================

# Java is called platform independent because Java source code

# is compiled into platform-independent bytecode.

# The bytecode can run on different operating systems

# if a compatible JVM is available.

# ==========================================================

# PLATFORM INDEPENDENCE

# ==========================================================

# Java Code

#     ↓

# Bytecode

#     ↓

# Windows JVM

# macOS JVM

# Linux JVM

# ==========================================================

# IMPORTANT POINT

# ==========================================================

# Java Bytecode → Platform Independent

# JVM → Platform Dependent

# ==========================================================

# WRITE ONCE, RUN ANYWHERE

# ==========================================================

# Java is commonly associated with the phrase:

# "Write Once, Run Anywhere"

# This means Java code can be compiled into bytecode

# and the bytecode can run on different platforms

# using a compatible JVM.

# ==========================================================

# JDK

# ==========================================================

# JDK is needed when we want to DEVELOP Java programs.

# Writing Java programs

# Compiling Java programs

# Debugging Java programs

# Running Java programs

# ==========================================================

# JRE

# ==========================================================

# JRE provides the environment required to RUN Java applications.

# It provides the JVM and runtime libraries required

# by Java applications.

# ==========================================================

# JVM

# ==========================================================

# JVM executes Java bytecode.

# JVM also manages important runtime operations such as:

# Memory management

# Garbage collection

# Bytecode execution
