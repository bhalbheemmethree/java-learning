# ==========================================================

# JAVA DAY 01

# INTRODUCTION TO JAVA, JDK, JRE & JVM

# ==========================================================

# ==========================================================

# WHAT IS JAVA?

# ==========================================================

# Java is a high-level, object-oriented, class-based

# programming language.

# Java was developed by Sun Microsystems.

# Java is widely used for backend development,

# enterprise applications, Android development,

# desktop applications and large-scale systems.

# ==========================================================

# FEATURES OF JAVA

# ==========================================================

# Important features of Java:

# 1. Platform Independent

# 2. Object-Oriented

# 3. Robust

# 4. Secure

# 5. Portable

# 6. Multithreaded

# 7. Automatic Memory Management

# ==========================================================

# PLATFORM INDEPENDENCE

# ==========================================================

# Java is platform independent because Java source code

# is compiled into bytecode.

# Bytecode can run on different operating systems

# using a suitable JVM.

# Example:

# Java Program

#       ↓

# Bytecode

#       ↓

# JVM

#       ↓

# Windows / macOS / Linux

# ==========================================================

# WRITE ONCE, RUN ANYWHERE

# ==========================================================

# Java follows the idea:

# Write Once, Run Anywhere.

# The same Java bytecode can run on different platforms

# when a compatible JVM is available.

# ==========================================================

# JAVA SOURCE CODE

# ==========================================================

# Java programs are written in source code files.

# Java source files use the .java extension.

# Example:

# Hello.java

# ==========================================================

# JAVA COMPILER

# ==========================================================

# The Java compiler is called javac.

# It converts Java source code into bytecode.

# Example:

# javac Hello.java

# The compiler produces:

# Hello.class

# ==========================================================

# BYTECODE

# ==========================================================

# Bytecode is the intermediate code generated

# by the Java compiler.

# Bytecode is stored inside a .class file.

# Example:

# Hello.java

#       ↓

# javac

#       ↓

# Hello.class

# ==========================================================

# WHAT IS JVM?

# ==========================================================

# JVM stands for Java Virtual Machine.

# JVM executes Java bytecode.

# JVM is responsible for executing Java programs

# and managing many runtime operations.

# JVM also provides memory management and

# garbage collection.

# ==========================================================

# WHAT IS JRE?

# ==========================================================

# JRE stands for Java Runtime Environment.

# JRE provides the environment required to run

# Java applications.

# JRE contains:

# 1. JVM

# 2. Runtime libraries

# Simplified structure:

# JRE

# ├── JVM

# └── Runtime Libraries

# ==========================================================

# WHAT IS JDK?

# ==========================================================

# JDK stands for Java Development Kit.

# JDK is used to develop Java applications.

# It provides development tools required by programmers.

# Important tools include:

# javac  → Java compiler

# java   → Runs Java programs

# jar    → Creates and manages JAR files

# javadoc → Generates documentation

# Simplified structure:

# JDK

# ├── Development Tools

# └── JRE

# ==========================================================

# JDK vs JRE vs JVM

# ==========================================================

# JDK → Used for developing Java applications.

# JRE → Provides the environment for running applications.

# JVM → Executes Java bytecode.

# Easy way to remember:

# JDK → DEVELOP

# JRE → RUN

# JVM → EXECUTE

# ==========================================================

# RELATIONSHIP BETWEEN JDK, JRE AND JVM

# ==========================================================

# JDK

#  ↓

# JRE

#  ↓

# JVM

# The JDK provides development tools.

# The runtime environment provides what is needed

# to run Java applications.

# The JVM executes the bytecode.

# ==========================================================

# JAVA PROGRAM EXECUTION FLOW

# ==========================================================

# Java source code:

# Hello.java

#       ↓

# Java Compiler

# javac Hello.java

#       ↓

# Bytecode

# Hello.class

#       ↓

# JVM

#       ↓

# Machine-level execution

#       ↓

# Output

# ==========================================================

# COMPILING A JAVA PROGRAM

# ==========================================================

# Suppose we have:

# Hello.java

# Compile using:

# javac Hello.java

# After compilation:

# Hello.class

# is created.

# ==========================================================

# RUNNING A JAVA PROGRAM

# ==========================================================

# After compilation, run the program using:

# java Hello

# Do not write:

# java Hello.java

# when using the traditional compile-and-run process.

# ==========================================================

# JVM AND PLATFORM

# ==========================================================

# Java bytecode is platform independent.

# JVM implementations are platform specific.

# Example:

# Windows has a JVM implementation.

# macOS has a JVM implementation.

# Linux has a JVM implementation.

# Each JVM can execute Java bytecode.

# ==========================================================

# GARBAGE COLLECTION

# ==========================================================

# Java provides automatic memory management.

# The JVM has a Garbage Collector.

# Garbage Collection removes objects that are

# no longer reachable by the program.

# This helps manage memory automatically.

# ==========================================================

# WHY JAVA IS POPULAR

# ==========================================================

# Java is popular because it provides:

# Platform independence

# Object-oriented programming

# Automatic memory management

# Multithreading

# Strong ecosystem

# Security features

# Large community

# Good support for enterprise applications
