# INTERVIEW QUESTIONS

# ==========================================================

# 1. WHAT IS JAVA?

# Java is a high-level, object-oriented programming language.

# Java source code is compiled into bytecode.

# Bytecode is executed by the JVM.

# ==========================================================

# 2. WHAT IS JDK?

# JDK stands for Java Development Kit.

# It is used to develop Java applications.

# It contains development tools such as the Java compiler.

# ==========================================================

# 3. WHAT IS JRE?

# JRE stands for Java Runtime Environment.

# It provides the environment required to run Java applications.

# ==========================================================

# 4. WHAT IS JVM?

# JVM stands for Java Virtual Machine.

# It executes Java bytecode.

# ==========================================================

# 5. WHAT IS THE DIFFERENCE BETWEEN JDK, JRE AND JVM?

# JDK → Used to develop Java applications.

# JRE → Provides the environment to run Java applications.

# JVM → Executes Java bytecode.

# ==========================================================

# 6. WHAT IS BYTECODE?

# Bytecode is the intermediate code generated by

# the Java compiler.

# It is stored in a .class file.

# ==========================================================

# 7. WHAT IS JAVAC?

# javac is the Java compiler.

# It converts .java source code into .class bytecode.

# ==========================================================

# 8. WHAT IS THE DIFFERENCE BETWEEN JAVA AND JAVAC?

# javac → Compiles Java source code.

# java → Runs the compiled Java program.

# ==========================================================

# 9. WHY IS JAVA PLATFORM INDEPENDENT?

# Java source code is compiled into platform-independent bytecode.

# This bytecode can run on different platforms using

# a compatible JVM.

# ==========================================================

# 10. IS JVM PLATFORM INDEPENDENT?

# No.

# JVM implementations are platform dependent.

# ==========================================================

# 11. WHAT IS THE EXTENSION OF A JAVA SOURCE FILE?

# .java

# Example:

# Main.java

# ==========================================================

# 12. WHAT IS THE EXTENSION OF A JAVA BYTECODE FILE?

# .class

# Example:

# Main.class

# ==========================================================

# 13. WHAT DOES "WRITE ONCE, RUN ANYWHERE" MEAN?

# Java code can be compiled into bytecode once.

# The same bytecode can run on different platforms

# using a compatible JVM.

# ==========================================================

# 14. WHAT HAPPENS WHEN WE COMPILE A JAVA PROGRAM?

# The Java compiler converts the .java source file

# into bytecode and creates a .class file.

# ==========================================================

# 15. WHAT HAPPENS WHEN WE RUN A JAVA PROGRAM?

# The JVM loads and executes the bytecode.

# ==========================================================

# ==========================================================

# QUICK REVISION

# ==========================================================

# JDK → Development

# JRE → Runtime Environment

# JVM → Executes Bytecode

# javac → Compiler

# java → Runs Java Program

# .java → Source Code

# .class → Bytecode
