# INTERVIEW QUESTIONS & ANSWERS

# INTRODUCTION TO JAVA, JDK, JRE & JVM

# ==========================================================


# 1. What is Java?

# Answer:
# Java is a high-level, object-oriented, class-based
# programming language developed by Sun Microsystems.
# It is widely used for backend, enterprise and
# large-scale application development.


# 2. Who developed Java?

# Answer:
# Java was developed by Sun Microsystems.
# James Gosling and his team played a major role
# in developing Java.


# 3. What are the important features of Java?

# Answer:
# Important features include:
# - Platform independence
# - Object-oriented programming
# - Robustness
# - Security
# - Portability
# - Multithreading
# - Automatic memory management


# 4. Why is Java platform independent?

# Answer:
# Java source code is compiled into platform-independent
# bytecode.
# The bytecode can be executed on different operating
# systems using a compatible JVM.


# 5. What is JDK?

# Answer:
# JDK stands for Java Development Kit.
# It is used to develop Java applications.
# It contains development tools such as the Java compiler
# and runtime components.


# 6. What is JRE?

# Answer:
# JRE stands for Java Runtime Environment.
# It provides the environment required to run
# Java applications.


# 7. What is JVM?

# Answer:
# JVM stands for Java Virtual Machine.
# It executes Java bytecode and performs various
# runtime operations such as memory management
# and garbage collection.


# 8. What is the difference between JDK, JRE and JVM?

# Answer:
# JDK → Used to develop Java applications.
# JRE → Provides the environment to run applications.
# JVM → Executes Java bytecode.


# Easy way to remember:

# JDK → DEVELOP
# JRE → RUN
# JVM → EXECUTE


# 9. What is Java bytecode?

# Answer:
# Bytecode is the intermediate code generated by the
# Java compiler.
# It is stored in a .class file and is executed by
# the JVM.


# 10. What is a .class file?

# Answer:
# A .class file contains the bytecode generated
# by the Java compiler from a Java source file.


# 11. What is the role of javac?

# Answer:
# javac is the Java compiler.
# It converts Java source code (.java) into
# bytecode (.class).


# 12. What happens when we run javac Hello.java?

# Answer:
# The Java compiler compiles Hello.java and normally
# generates a Hello.class file containing bytecode.


# 13. What happens when we run java Hello?

# Answer:
# The Java launcher starts the Java application.
# The JVM loads and executes the bytecode of the
# Hello class.


# 14. What is WORA?

# Answer:
# WORA means "Write Once, Run Anywhere".
# It means Java bytecode can run on different
# platforms when a compatible JVM is available.


# 15. Is Java platform independent?

# Answer:
# Yes.
# Java bytecode is platform independent.
# The JVM implementation is platform specific.


# 16. Is JVM platform independent?

# Answer:
# No.
# JVM implementations are platform specific.
# For example, the JVM implementation for macOS
# differs from the one for Windows.


# 17. What is the role of JVM in Java?

# Answer:
# The JVM loads and executes Java bytecode.
# It also handles runtime tasks such as memory
# management and garbage collection.


# 18. What is Garbage Collection?

# Answer:
# Garbage Collection is the automatic process of
# identifying and reclaiming memory occupied by
# objects that are no longer reachable by the program.


# 19. What is automatic memory management in Java?

# Answer:
# Java automatically manages memory using the JVM
# and Garbage Collector.
# Developers do not normally need to manually free
# object memory.


# 20. Why is Java widely used for backend development?

# Answer:
# Java provides:
# - Strong object-oriented features
# - Good performance
# - Multithreading
# - Security
# - Large ecosystem
# - Strong database support
# - Mature backend frameworks such as Spring
# - Good support for large-scale applications
